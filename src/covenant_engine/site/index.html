How it works

The model only fills fixed structures. Code decides anything deterministic and checks everything. What code can't confirm goes to a person.

  1. Read the documentLive text from the PDF with struck redline words removed; every section, definition and cross-reference the covenants depend on.
  2. Extract into fixed structuresClaude records covenant levels by test date, relief periods and step-ups, and every add-back and deduction with its cap and exact quote. GPT answers the same questions without seeing Claude's answers.
  3. Check everythingEvery quote is verbatim in the agreement, every number appears in its quote, every clause is covered, the two models are compared, each quote is found on its page.
  4. Review and sign offThe analyst works only the items code couldn't confirm: confirm, change the value, or note the document that's needed. Then signs off.
  5. Testing workbookOne click builds the Excel: a test calendar to maturity, plain-English definitions, and a test sheet where the agreement's caps apply by formula. No model after sign-off.

What the bank gets

The agreement is read once. After sign-off, every quarterly test runs off structured data with no model and no re-reading, and every number traces back to its sentence.
